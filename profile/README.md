# Nezanuha

Open source tools for building web applications: a Python web framework, a CSS
component library, and the pieces that go around them. All MIT licensed.

## Buraq

A high-performance async Python web framework, batteries included, built for AI
applications and high-traffic APIs.

[buraqproject.com](https://buraqproject.com) · [repository](https://github.com/nezanuha/buraq)

## Frutjam

65+ Tailwind CSS v4 components with no JavaScript at all. WCAG AA contrast on
every theme, RTL built in. Install it as a Tailwind plugin and the components
are there.

[frutjam.com](https://frutjam.com) · [repository](https://github.com/nezanuha/frutjam)

## Markdown Text Editor

A markdown editor that enhances the textarea you already have instead of
replacing it, so form submission, validation and required fields keep working.
Paste a screenshot and it uploads.

[docs](https://frutjam.com/plugins/markdown-editor) · [repository](https://github.com/nezanuha/markdown-text-editor)
